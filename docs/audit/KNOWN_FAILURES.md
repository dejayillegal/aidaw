# Root-Cause Analysis & Known Failures Addressed in v3.0

## 1. Root-Cause Audit (Assumptions A–J)

| ID | Defective Assumption in v2.x | Root Cause Identified in Codebase | v3.0 Architectural Fix |
| :--- | :--- | :--- | :--- |
| **RCA-A** | Randomization alone creates musical originality | `TechnoHeuristicEngine.generateHumanizedMidiArray` selected `variantId = Math.abs(seed) % 4` and repeated identical 1-bar patterns across all 16 bars. | Introduced `ProjectConditionedComposer` with 8 distinct composition strategies, multi-bar phrase families, motif transformations (inversion, rotation, Euclidean, call-and-response), and section-aware arrangement evolution. |
| **RCA-B** | Four static 1-bar variations provide sufficient depth | `generateHumanizedMidiArray` looped `bar = 0..15` with the same 1-bar step array, causing static repetition across 16 bars. | Added multi-bar phrase development (2-bar, 4-bar, 8-bar evolving motifs, turnaround fills on bars 4/8/12/16, breakdown dropouts, and Session View 4-scene clip variations per track). |
| **RCA-C** | Unanalyzed layer injection ignores existing project context | `injectTechnoLayerIntoXml` only checked track names and `rootKey`, ignoring existing kick onsets, note density, register occupancy, and harmonic ambiguity. | Built `analyzeProjectMusicalProfile()` which extracts kick onset grid, low-end occupancy, syncopation index, pitch-class distribution, and phrase density contour before composing any layer. |
| **RCA-D** | No novelty or similarity verification | Repeated regenerations could produce near-identical rhythmic or pitch contours. | Built `evaluateGenerationNovelty()` computing rhythmic Jaccard distance, pitch-class cosine distance, interval edit distance, and source compatibility scores, with bounded candidate selection. |
| **RCA-E** | Unchecked `.als` XML export without invariant verification | `compressXmlToAlsBlob` compressed modified XML without checking unique `Id`/`NoteId` invariants, sidechain source references, or round-trip parse validity. | Added `validateAlsProjectCadence()` verifying gzip magic, XML schema integrity, unique IDs, sidechain source existence, and semantic round-trip re-import consistency. |
| **RCA-F** | Loudness metering conflated Peak dBFS with LUFS | `MasterSpectrumAnalyzer` only computed peak byte amplitude without ITU-R BS.1770 K-weighting or true RMS vs. LUFS separation. | Added separated **True Peak dBFS**, **RMS dB**, and **K-Weighted Short-Term LUFS** telemetry in `MasterSpectrumAnalyzer`. |
| **RCA-G** | WAV export fixed at 16-bit PCM | `encodeAudioBufferToWavBlob` used 16-bit `Int16` encoding. | Upgraded WAV encoder to support true **24-bit PCM** (`3 bytes/sample`, `8,388,607` full-scale integer) studio lossless rendering while retaining full compatibility. |
| **RCA-H** | Track overwrites during bulk generation | `handleInjectAllMissingLayers` regenerated all 4 layers even when a user wanted to lock specific tracks. | Added per-track `locked` state (`handleToggleTrackLock`) and selective regeneration so locked tracks are strictly protected. |
