# Declared ALS boundary

| Area | Classification | Evidence / limitation |
|---|---|---|
| Gzip/XML file parsing | Partially supported | Repository fixtures and scoped structural regressions. XML validity is not musical fidelity. |
| MIDI arrangement notes/clips | Partially supported | Scoped identity, fine timing, probability and app motif/ghost projection regressions. New metadata attributes are not native Live certification. |
| Native project snapshots | Supported subset | Canonical tracks/plan/settings round trips; assets remain references. |
| Unknown XML / plugin state | Preserved but not executable where retained | Existing opaque preservation contracts; arbitrary native groups/expression/routing not losslessly certified. |
| Plugin replacement/bypass/restore | Browser approximation / explicit decision | Existing registered factories execute supported replacement DSP. Original plugin XML remains preserved. |
| Tempo/meter maps | Partially supported | Model/projection exist; scalar live scheduling paths remain. |
| Audio references / warp / packs | Partially supported or unsupported | Requires exact accessible source assets; do not fabricate media or silently substitute. |
| VST3/AU/Max for Live hosting | Unsupported | No universal native host/runtime/licensing qualification. |
| Live versions | Not tested in native Live | No licensed runtime on this machine. Sample files alone do not prove version compatibility. |
