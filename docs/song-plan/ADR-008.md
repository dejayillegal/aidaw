# ADR-008 — Seeded composition intention and single-owner insert gain

Status: engineering candidate; musical and release qualification open.

The reviewed main is `1b889a524427a6eadc80d683d4507c68311f614e`. Its Full Track handler generated a starter then partitioned existing notes. Insert processors and an estimated channel multiplier both applied gain/saturation; Reverb clamped milliseconds as seconds; the stab added an unrequested minor third; acid invented duration-based portamento. Native browser recovery also reproduced stale XML despite correct recovered canonical MIDI.

Keep the existing canonical project, command bus/history, XML preservation, queue journal and shared native Web Audio renderer. Add optional versioned SongPlan intention to that domain, with phrase materialization producing ordinary editable clips, notes and the existing filter-energy automation. There is no second playback engine. Full Track initializes a new queue identity; Compose, added layers and selected ranges use the same plan. Locks exclude tracks; scoped replacement preserves all events outside the selected onset range, Session slots and user mixer state. Changing timeline extent alone retains the composed plan duration and displays that distinction.

The plan owns seed/version, style, meter/tempo, modal or evolving harmonic events/voicings, motif families, role spans/density/focus, sections, phrases and typed transition decisions. Role materialization includes negative space, independent pickups/withdrawals, offbeat bass, call/response acid, upper-register voice-led chord/pad voicings and a drum mix-out. Transition preparation becomes MIDI fills, bass/kick withdrawals, chord pickups and supported filter-energy changes; effect tails remain on the persistent channel graph. General send/return parameter automation, arbitrary riser sample libraries and every transition vocabulary are not claimed implemented.

Actual insert nodes own gain and saturation in order. Channel/VCA faders no longer apply insert estimates; native voice synthesis no longer inserts another estimated saturation stage. Analysis-only approximate PCM remains separate and is not exported as production WAV. The limiter no longer applies its ceiling as another output gain. Ordinary stab oscillators share the supplied note pitch; intentional chord MIDI devices remain explicit. Acid owns preceding sounding-pitch state, explicitly articulated glide, monophonic retirement and resonance compensation. Ducking reads actual routed source events and effective audibility, including Session evaluation.

Conversion algorithm version 2 converts declared units before clamping and descriptor generation. A v1 record migrates only when every retained field equals the reproducible v1 record for the exact raw parameters/hash; it is not inferred from the device ID. Recovery checks the original envelope checksum before this compatibility migration and persists successful migration through the existing atomic backup path. Invalid, changed, future and ambiguous records remain blocked. The targeted snapshot repair command inspects raw/expected/actual data, requires exact track/device/source hash, rejects future versions and writes a separate file with exclusive creation. No storage clearing or global descriptor rebuilding is performed.

Rollback requires a v2 conversion-aware reader for newly saved records. Retain original snapshots/journals and backups. Old readers reject future conversion versions; reverting source does not migrate data backward. XML app metadata and note articulation attributes are synthetic round-trip evidence, not licensed Ableton certification.

Constant 4/4 composition is explicit; existing variable tempo/meter scheduling limitations remain. SongPlan generation rejects unsupported meters. Long export retains the existing memory preflight; no long-song streaming solution or physical Android reliability is claimed. The original G1–G8 meanings, numeric tolerances and external prerequisites are unchanged. Test counts, deterministic arrangements and measured audio are engineering evidence, not producer listening approval.
