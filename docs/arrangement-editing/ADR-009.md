# ADR-009: Identity-scoped Arrangement edits and live reconciliation

Status: Implemented, 4 November 2026. This decision does not certify Ableton parity or the acceptance gates.

Clip and note edits require track, clip and note identities. Native note IDs may repeat in separate clips. Pointer movement is a local preview; pointer release commits one command. Escape/pointer cancellation discards the preview. Numeric controls provide precise keyboard-accessible editing of the same domain operations. The existing command bus remains the owner of detached snapshots, lock protection, XML synchronization and undo/redo.

Coordinates remain exact finite beat values. Moving a clip shifts its notes; trimming retains hidden notes. Range deletion removes the specified half-open interval and retains the prefix/suffix. Notes crossing a split/deletion boundary become explicit continuation notes. This retriggers an instrument envelope; it is not a promise of phase-continuous audio or native tie behavior. Shuffle ripples the affected layer only.

Manual edits mark their affected clips as user-owned. Scoped SongPlan composition excludes those complete spans, including their negative space. A visible, undoable protection control permits regeneration when deliberately released. This conservative clip-level protection avoids guessing whether individual notes or rests are expendable. Full composition remains an explicit broader replacement operation; track locking is the stronger protection.

XML note templates are captured per source clip before reconciliation, preserving opaque note attributes even when source note IDs repeat. Pending multi-source template references are consumed after successful XML projection, before publishing canonical history; later clones reference their immediate native source. Multi-source consolidation rejects incompatible opaque clip attributes/children instead of silently discarding them. General native loop, envelope, expression and device fidelity still requires the original interoperability qualification.

Compiled event signatures include exact score coordinates, identities, articulation and probability. A changed Arrangement layer retires its queued/active sources and removes that layer's scheduling keys. Unchanged layers keep their sustains and audio-clock anchors. Editing an already-sounding note stops its old voice; the new note is scheduled at its next eligible onset, not retroactively retriggered. Existing shared return buses remain connected.

Live master reconciliation uses the declared fader and the current automation trim, without extra glue-drive makeup. Initial, updated and offline master gain therefore use the same declared policy. Captured full-song live/offline parity remains a separate acceptance requirement.
